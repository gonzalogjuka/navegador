#   Antes de correr, crear <carpeta temporal>\settings.json con: {"RamBudgetMb":128,"BudgetKeepRecentMinutes":0}
#   dist\Navegador.exe --data-dir <carpeta temporal> --automation tools\smoke\formulario.txt
# En el log: discard_skipped (why=unsaved_input) para la pestaña 1, budget_discard para las otras de fondo, y el
